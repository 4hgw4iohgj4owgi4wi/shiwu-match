# 校园失物招领智能匹配系统 · 华东交通大学

在线体验（单文件离线演示版）：**https://4hgw4iohgj4owgi4wi.github.io/shiwu-match/**

打开即可体验完整流程：手机号登录（验证码任意 6 位）→ 描述失物 → AI 匹配 → 认领核验 → 失物订阅 → 捡拾者入库 → 自动推送，支持中英文切换。

## 说明

- `index.html` 为自包含单文件页面，内嵌 22 件失物的实拍照片，无需后端、无需联网依赖，双击本地文件同样可运行。
- 页面检测到没有后端服务时会自动进入演示模式，检索为浏览器端模拟打分；真实环境（本地运行 `run.bat`）使用中文 CLIP 模型做图文跨模态检索。

## 技术方案

- 中文 CLIP（OFA-Sys/chinese-clip-vit-base-patch16）图文双塔，余弦相似度检索
- 融合排序：视觉相似 70% · 时间衰减 18% · 地点匹配 12%
- 时间线校验（丢失时间晚于捡拾时间的候选自动排除）、同物多角度聚类去重
- 认领二次图像核验，相似度超过阈值才解锁联系方式
- FastAPI + Uvicorn 后端，前端零依赖单页应用，中英双语
